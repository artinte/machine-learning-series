1. 两数之和

解题思路：最容易想到的就是两个 for 循环进行遍历所有情况。

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        length = len(nums)
        for i in range(0, length):
            for j in range(i + 1, length):
                if nums[i] + nums[j] == target:
                    return [i, j]

上述算法时间复杂度为 \(O(n^2)\) ，下述算法使用一个 dict 记录所有遍历的数值和它们的下标。

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # Key is the number and value is its index in the vector.
        temp_dict = {}
        length = len(nums)
        for i in range(length):
            complement = target - nums[i]
            if complement in temp_dict:
                return [temp_dict[complement], i]
            else:
                # Number is not found, put it in the dict.
                temp_dict[nums[i]] = i

2. 两数相加

解题思路：遍历链表，保留 进位 (Carry) ，下一个节点相加的时候需要。另外需要注意两个链表的长度不一致。

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()
        result = dummy
        carry = 0
        while l1 or l2 or carry:
            num = carry
            if l1:
                num += l1.val
                l1 = l1.next
            if l2:
                num += l2.val
                l2 = l2.next
            
            carry = num // 10
            dummy.next = ListNode(num % 10)
            dummy = dummy.next
        return result.next

3. 无重复字符的最长子串

解题思路：使用暴力解法，复杂度是 \(O(n^3)\) ，容易超时。

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        length = len(s)
        max_length = 0
        for i in range(0, length):
            for j in range(i + 1, length + 1):
                temp_list = []
                for k in range(i, j):
                    if s[k] in temp_list:
                        break
                    else:
                        temp_list.append(s[k])
                if len(temp_list) > max_length:
                    max_length = len(temp_list)
        return max_length

滑动窗口是一种 双指针技巧，它用两个变量 left 和 right 来 动态调整窗口大小，确保窗口内的字符是不重复的：

  • right 指针右移扩展窗口（向右加入新字符）。
  • 如果 s[right] 已经在窗口内（重复出现），则移动 left 指针缩小窗口，直到 s[right] 不再重复。
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 存储当前窗口内的字符
        char_set = set()
        max_length = 0
        # 左指针
        left = 0 
        for right in range(len(s)):
            while s[right] in char_set:
                char_set.remove(s[left])
                left += 1
            char_set.add(s[right])
            max_length = max(max_length, right - left + 1)
        return max_length

4. 寻找两个正序数组的中位数

解题思路：假设选择数组 nums1 的一个分割点 i ，将其分为两个部分。数组 nums2 必须有一个分割点 j ，使得左边部分的总元素个数等于右边部分的总元素个数，即 \(i + j = (len(nums1) + len(nums2) + 1) / 2\) 。

import sys

class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        if len(nums1) > len(nums2):
            # 确保 nums1 是较短的数组
            nums1, nums2 = nums2, nums1

        len_a, len_b = len(nums1), len(nums2)
        # 对 nums1 进行二分查找
        left, right = 0, len_a
        while left <= right:
            # 对 nums1 进行中位分割
            i = (left + right) // 2
            # 对 nums2 进行中位分割
            # i + j = (len_a + len_b + 1) / 2
            j = (len_a + len_b + 1) // 2 - i
            if i < len_a and nums2[j - 1] > nums1[i]:
                # nums1 太小
                left = i + 1
            elif i > 0 and nums1[i - 1] > nums2[j]:
                # nums1 太大
                right = i - 1
            else:
                max_left = max(nums1[i - 1] if i > 0 else -sys.maxsize,
                                nums2[j - 1] if j > 0 else -sys.maxsize)
                if (len_a + len_b) % 2 == 1:
                    # 奇数个数
                    return max_left
                
                min_right = min(nums1[i] if i < len_a else sys.maxsize,
                                nums2[j] if j < len_b else sys.maxsize)
                # 偶数个数
                return (max_left + min_right) / 2.0

5. 最长回文子串

解题思路：构建一个二维数组 dp，其中 dp[i][j] 表示从字符串 s 的第 i 个字符到第 j 个字符的子串是否是回文。

基本状态：

  • dp[i][i] = True，每个单独的字符都是回文。
  • dp[i][i+1] = True 如果 s[i] == s[i+1]，即两个连续字符相等时，它们是回文子串。

状态转移（长度逐步增加）：对于任意 i 和 j，如果 s[i] == s[j] 且 dp[i+1][j-1] == True，那么 dp[i][j] 也应该为 True，即 s[i...j] 是回文子串。

class Solution:
    def longestPalindrome(self, s: str) -> str:
        length = len(s)
        dp = [[False] * length for _ in range(length)]
        max_len = 1
        # 记录最长回文起始位置
        start = 0

        for i in range(length):
            # 单个字符都是回文
            dp[i][i] = True

        for  i in range(length - 1):
            # 判断所有长度为 2 的子字符串
            if s[i] == s[i + 1]:
                dp[i][i + 1] = True
                start = i
                max_len = 2
        
        for sub_len in range(3, length + 1):
            # 子字符串的长度从 3 到 n
            # i 和 j 表示字符串的起点到终点下标
            for i in range(length - sub_len + 1):
                j = i + sub_len - 1
                if s[i] == s[j] and dp[i + 1][j - 1]:
                    dp[i][j] = True
                    if sub_len > max_len:
                        max_len = sub_len
                        start = i

        return s[start:start + max_len]

6. Z 字形变换

解题思路：使用一个变量 direction 记录当前的走动的方向。

class Solution:
    def convert(self, s: str, numRows: int) -> str:
        if numRows == 1 or numRows > len(s):
            return s
        
        # 记录每一行的信息
        rows = [""] * numRows
        direction = 1
        # 记录当前行
        index = 0

        for c in s:
            rows[index] += c

            # 方向变化：到底部转向上，到顶部转向下
            if index == 0:
                # 向下
                direction = 1
            elif index == numRows - 1:
                direction = -1
    
            index += direction

        return "".join(rows)

7. 整数反转

思路：重点解决如何防止数据溢出。

class Solution:
    def reverse(self, x: int) -> int:
        result = 0
        negative = x < 0
        x = x if x > 0 else -x

        int32_max = 2**31 - 1
        while x != 0:
            tail = x % 10
            # 数据溢出
            if (int32_max - tail) / 10 < result:
                return 0
            result = result * 10 + tail
            x = x // 10
        
        return -result if negative else result

8. 字符串转换整数 (atoi)

思路：注意数据如果过大需要截断。

class Solution:
    def myAtoi(self, s: str) -> int:
        s = s.lstrip()
        if len(s) == 0:
            return 0
        postive = True
        if s[0] == '-':
            postive = False
            s = s[1:]
        elif s[0] == '+':
            s = s[1:]
        
        pos_max = 2**31 - 1
        neg_max = -2**31

        temp = ''
        check_zero = True
        for c in s:
            if check_zero:
                if c == '0':
                    continue
                else:
                    check_zero = False

            if c >= '0' and c <= '9':
                if len(temp) > 0 and int(temp) > (pos_max - int(c)) // 10:
                    return pos_max if postive else neg_max
                temp += c
            else:
                break
        if len(temp) ==0:
            return 0
        else:
            return int(temp) if postive else -int(temp)

9. 回文数

思路：将整数转化为字符串直接比较。

class Solution:
    def isPalindrome(self, x: int) -> bool:
        if x < 0:
            return False

        s = str(x)
        for i in range(len(s) // 2):
            if s[i] != s[-1 - i]:
                return False
        return True

10. 正则表达式匹配

题目看起来简单，但是实际上要困难很多，常规方法（条件判断）很难写清楚，采用动态规划的方案，从最小的答案逐渐扩大找到解决方案。

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        dp = [[False] * (len(p) + 1) for _ in range(len(s) + 1)]
        dp[0][0] = True

        # Deals with patterns like a* or a*b* or a*b*c*.
        for i in range(2, len(p) + 1):
            if p[i - 1] == '*':
                dp[0][i] = dp[0][i - 2]

        for i in range(1, len(s) + 1):
            for j in range(1, len(p) + 1):
                if p[j - 1] == '.' or p[j - 1] == s[i - 1]:
                    dp[i][j] = dp[i - 1][j - 1]
                elif p[j - 1] == '*':
                    if p[j - 2] == s[i - 1] or p[j - 2] == '.':
                        dp[i][j] = dp[i][j - 2] or dp[i][j - 1] or dp[i - 1][j]
                    else:
                        dp[i][j] = dp[i][j - 2]
                else:
                    dp[i][j] = False
        return dp[len(s)][len(p)]

11. 盛最多水的容器

思路：暴力解法会超时。

class Solution:
    def maxArea(self, height: List[int]) -> int:
        volume_max = 0
        for i in range(0, len(height)):
            for j in range(i + 1, len(height)):
                volume = (j - i) * min(height[i], height[j])
                if volume_max < volume:
                    volume_max = volume
        return volume_max

采用双指针记录左右木板的位置，左边模板短就往右移，右边模板短就左移。

class Solution:
    def maxArea(self, height: List[int]) -> int:
        volume_max = 0
        left = 0
        right = len(height) - 1
        while left < right:
            volume = (right - left) * min(height[left], height[right])
            if volume > volume_max:
                volume_max = volume
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return volume_max
