160. 相交链表

思路：两个指针 a 和 b 会在两个链表上分别遍历。如果 a 到达链表 A 的末尾，则跳转到链表 B 的头部；同理，b 到达链表 B 的末尾时跳转到链表 A 的头部。通过这种方式，两指针最终会在交点相遇。若没有交点，它们最终会同时到达 None ，此时返回 None 。

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        curA = headA
        curB = headB

        while curA != curB:
            curA = headB if curA == None else curA.next
            curB = headA if curB == None else curB.next
        
        return curA
